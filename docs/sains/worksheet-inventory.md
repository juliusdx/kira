## Notes for anyone building on this material

**Roughly 45 of 81 pages contain at least one item that cannot exist without its artwork** — teeth labelling, digestive-tract labelling, plant identification (虎尾兰 vs 苔藓), animal-skull comparison, meniscus reading, grid-paper area estimation, cube-count volume. An image asset library is a hard requirement, not a nice-to-have.

**Sequencing (排列 1–6) for the digestion process recurs across three different publishers** — it is the single most reusable auto-gradable item type in the set and a good first build target.

**The TP5/TP6/KBAT tier is entirely free-response** — "设计一个营养均衡的餐点并写出原因", "预测人类将面临的状况", "写出计算铁钉体积的步骤". A product that only auto-grades TP1–TP3 cannot claim PBD alignment.

**Terminology is Chinese-only but the scaffolding is Malay.** Pupils learn 地下茎, 吸芽, 孢子 while the assessment system speaks in SP codes, TP bands, Bahagian B, and Year 4+ transition material uses batang bawah tanah, sucker, spora. A CN↔BM↔EN glossary per topic is high-value and nobody seems to publish one.

**Duplicates:** 0071/0072, 0039/0042, 0033/0037 are re-photographs of the same page. De-duplicate on content, not filename.

**Image quality:** ~11 of 81 returned no OCR at all from Google. Several are rotated 90°/180° (0023, 0024, 0033, 0035, 0040, 0048, 0073) or shot at an angle with page curl. Any ingestion pipeline needs orientation detection and a dewarp step.

**Ground truth is available.** The marked scripts (0073, 0074, 0081–0087) carry red teacher corrections and scores — a validation set for any auto-extraction pipeline.
